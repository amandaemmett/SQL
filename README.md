# Amanda Emmett's SQL Portfolio

This repository contains SQL queries I've written to answer real business questions — from customer behavior to sales performance to data cleanup. Each project includes the query alongside the question it answers.

📧 Questions? Reach out: amanda.emmett99@gmail.com

## Projects

| Project | What it demonstrates |
|---|---|
| [Customer and Order Analytics](./Customer%20and%20Order%20Analytics.sql) | Multi-table joins and aggregations to answer sales and customer behavior questions (order volume, revenue by product, top spenders) |
| [Furniture Store Database and Stats](./Furniture%20Store%20Database%20and%20Stats.sql) | Querying a large retail dataset to surface KPIs and clean underlying data |
| [Record Label SQL project](./Record%20Label%20SQL%20project.sql) | Complex multi-table joins and CTEs on the Chinook music database — sales by agent, top-selling genres and media types by year, customer/invoice analysis |
| [City Bike Lane Data Analysis](./City%20Bike%20Lane%20Data%20Analysis.sql) | Window functions (`AVG() OVER PARTITION BY`) and conditional logic (`CASE`) to rate bike lane safety and recommend "Remove," "Improve," or "Leave As-Is" |
| [PostgreSQL Netflix Data Analytics Project](./PostgreSQL%20Netflix%20Data%20Analytics%20Project.sql) | PostgreSQL table design and joins across titles/cast data to answer content and catalog questions |
| [Spotify Data Analytics Project](./Spotify%20Data%20Analytics%20Project.sql) | Aggregation and a CTE to rank tracks by danceability/popularity and flag "Top Star" artists by average popularity |
| [Bank Products](./Bank%20Products.sql) | Filtering and aggregation to match banking products to customer needs (rate, fees, minimum balance) |
| [Toy Store Database and Stats](./Toy%20Store%20Database%20and%20Stats.sql) | Revenue and profit calculations per item, including a transaction-wrapped bulk update |
| [Superstore Analysis](./Superstore%20Analysis.sql) | Aggregation across product categories to analyze pricing, ratings, and stock levels |
| [Fortune 500 Analysis](./Fortune%20500%20Analysis.sql) | `CASE` statements and `GROUP BY`/`HAVING` to bucket companies by employee count and filter aggregated results (e.g., industries with average tenure ≥ 6 years) |
| [Author Analytics](./Author%20Analytics.sql) | Multi-table joins (including a self-join for book sequels) and data cleanup (`UPDATE`, `ALTER TABLE`) across a custom authors/books schema |
| [Editing a Database](./Editing%20a%20Database.sql) | Core data manipulation — `ALTER TABLE`, `UPDATE`, and `DELETE` — on a custom streaming-service schema |
